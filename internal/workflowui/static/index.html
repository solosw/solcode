SMARTER DECISIONS

Jev · System One

TypeSafe System One decides how work is routed: which skill or tool fits, how to classify a memory, whether an action looks unsafe. It never writes code and never replaces the chat model. Every decision has a fallback, so leaving this off changes nothing. Choose the hosted API or a local Kev GGUF decision backend.

Kev GGUF · in-process llama.cpp · GPU required, no CPU fallback. Enter the filename above; all local models load from ~/.solcode/models.

SEMANTIC SEARCH

Embedding

Optional vector embeddings for semantic search. Choose an OpenAI-compatible API or a local GGUF model. The project index lives under ProjectStateDir/embeddings (sibling of knowledge.db); all local GGUF files live in ~/.solcode/models (GPU only). Off by default.

CONTEXT THAT LASTS

Memory organizer

Generates /compact session summaries and extracts long-term memory using a local GGUF model or an independently configured API. API mode sends session content to that endpoint; local mode never falls back to an API. While enabled, the chat model's own memory-writing tools are disabled. The compress tool uses a summary written by the current AI and does not call this backend.
