Jev (System One)

TypeSafe System One decides how work is routed: which skill or tool fits, how to classify a memory, whether an action looks unsafe. It never writes code and never replaces the chat model. Every decision has a fallback, so leaving this off changes nothing. Choose the hosted API or a local OpenJev/Laya ONNX backend.
